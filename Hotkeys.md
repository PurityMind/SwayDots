
# **This is hotkeys for my dotfiles**
|       Hotkey       |      Action      |
|--------------------|------------------|
|    <kbd>Super</kbd> + <kbd>Return</kbd>         |       Open a terminal (Alacritty)      |
|    <kbd>Super</kbd> + <kbd>D</kbd> | Open launcher (rofi) |
|    <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>Q</kbd> | Close Program |
|    <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> | Exit from Sway |
|    <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> | Restart Sway |
|    <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>Space</kbd> | Toggle floating mode
|    <kbd>Print</kbd> | Take a screenshot (Flameshot) |
